# Explain Topic

When the user asks you to explain a technical topic:

1. Start with a simple definition.
2. Explain why it is useful.
3. Give a small real-world example.
4. Explain the important components.
5. End with a short summary.

Keep the explanation beginner-friendly.

If the topic is related to software development, include a small code example when useful.
