# Summarize Text

When the user provides text and asks for a summary:

1. Identify the main topic.
2. Extract the most important points.
3. Remove unnecessary repetition and details.
4. Preserve important technical terms, names, numbers, and facts.
5. End with a one-line conclusion.

Use this format:

## Summary

<2-4 sentence summary>

## Key Points

- Point 1
- Point 2
- Point 3

## Important Details

- Important detail 1
- Important detail 2

## Conclusion

<one-line conclusion>

Keep the summary concise and easy to understand.
